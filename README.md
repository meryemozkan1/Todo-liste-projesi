# TaskMaster — Professional To-Do App

TaskMaster is a lightweight, responsive to-do list application for organizing everyday tasks. It is built with HTML, CSS, and vanilla JavaScript, with no build tools or installation required.

## Live Demo

Try TaskMaster here: [https://meryemozkan1.github.io/Todo-liste-projesi/](https://meryemozkan1.github.io/Todo-liste-projesi/)

## Features

- Add tasks to your list.
- Search and filter tasks as you type.
- Remove individual tasks or clear the entire list.
- Keep tasks saved in your browser with `localStorage`, including after a page refresh.
- Use a responsive interface designed for desktop and mobile screens.

## Built With

- HTML5
- CSS3
- Vanilla JavaScript
- Browser Local Storage API

## Getting Started

No dependencies or build steps are required.

1. Clone or download this repository.
2. Open `index.html` in a web browser.
3. Add a task using the input field, or search for an existing task.

## Usage

Enter a task in the input field and select **Add task**. Use the search field to filter your list, the delete button on a task to remove it, or **Clear all tasks** to empty the list. Your tasks are stored locally in the browser.
